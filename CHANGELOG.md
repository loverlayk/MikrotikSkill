# Changelog

## 1.1.0

- Incremental page synchronization using SHA-256 hashes.
- Detects new, changed, unchanged, and removed pages.
- Generates a sync manifest and machine-readable sync summary.
- Added scheduled GitHub Actions synchronization.
- Added manual workflow dispatch.
- Added automatic commit of changed references.
- Added automatic GitHub Release creation on documentation changes.
- Added clean rebuild support.
