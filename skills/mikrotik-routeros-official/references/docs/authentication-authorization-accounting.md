# AAA and User Management

This section is about who can use the router and the network behind it, what each user can do, and how the use is counted.

- [User](user) has the accounts that manage the router itself.
- [Certificates](certificates) has the certificates and keys that the secure services of the router use.
- [RADIUS](radius) lets a central server authenticate the users of PPP, DHCP, HotSpot, Dot1X, IPsec, wireless and the router login.
- [User Manager](user-manager) is a RADIUS server that runs on RouterOS.
- [PPP AAA](ppp-aaa) has the users and profiles of the PPP servers: PPPoE, L2TP, SSTP and others.
- [Dot1X](dot1x) authenticates the devices on Ethernet ports with IEEE 802.1X.
- [HotSpot](hotspot-captive-portal/) shows a login page to the users of a network before they get access.
