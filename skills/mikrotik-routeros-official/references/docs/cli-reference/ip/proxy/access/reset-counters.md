-----------

## ip/proxy/access/reset-counters 
**Type:** Command

Resets the `hits` counter of the given rules in [`/ip/proxy/access`](../access/), for example `/ip/proxy/access/reset-counters [find comment=test]`. For an overview, see [Web Proxy](../../../../network-management/proxy/web-proxy).
