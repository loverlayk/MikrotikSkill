## ip/hotspot/reset-html 
**Type:** Command

The `/ip/hotspot/reset-html` command writes the default pages to the HTML directory of a HotSpot server. It takes the name of the server, for example `/ip/hotspot/reset-html hotspot1`. Changes to the default page files in this directory are lost. See [HotSpot customisation](../../../authentication-authorization-accounting/hotspot-captive-portal/hotspot-customisation).
