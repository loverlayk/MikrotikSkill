# reset-counters

> The /ip/hotspot/user/reset-counters command sets the uptime, byte, and packet counters of the selected users to zero. A user who has reached limit-uptime or a byte limit can log in again after it.

-----------

## ip/hotspot/user/reset-counters 
**Type:** Command

The `/ip/hotspot/user/reset-counters` command sets the uptime, byte, and packet counters of the selected users to zero. A user who has reached `limit-uptime` or a byte limit can log in again after it.
