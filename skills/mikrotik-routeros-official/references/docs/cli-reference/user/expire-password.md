## user/expire-password 
**Type:** Command

Expires the selected users' passwords (sets the `E` flag in [`/user`](.)). At the next interactive login the user is asked to set a new password; setting a new password with `/user/set` also clears the flag. See [User](../../authentication-authorization-accounting/user) for the full guide.
