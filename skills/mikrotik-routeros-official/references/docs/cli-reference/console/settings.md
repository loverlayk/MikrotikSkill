# settings

> RouterOS settings reference for /console/settings.

-----------

## console/settings 
**Type:** Settings Directory

<ArgTable c1="Argument" c2="Type" c3="Description">
<ArgTableRow arg="sanitize-names" typ="bool">Replaces reserved characters (\\ / : * ? |) with underscores in file and script names. Default: `no`.</ArgTableRow>
<ArgTableRow arg="log-script-errors" typ="bool">Writes errors of scripts that run in the background to the log. Default: `yes`.</ArgTableRow>
<ArgTableRow arg="tab-width" typ="num">Tab width in the full-screen editor. Default: `4`.</ArgTableRow>
</ArgTable>
