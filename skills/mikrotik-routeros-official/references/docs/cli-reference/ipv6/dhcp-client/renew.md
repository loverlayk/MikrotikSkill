# renew

> Renews the current addresses and prefixes immediately, without waiting for the renewal time. If the server does not answer, the client keeps its address and prefix while it retries.

-----------

## ipv6/dhcp-client/renew 
**Type:** Command

Renews the current addresses and prefixes immediately, without waiting for the renewal time. If the server does not answer, the client keeps its address and prefix while it retries.
