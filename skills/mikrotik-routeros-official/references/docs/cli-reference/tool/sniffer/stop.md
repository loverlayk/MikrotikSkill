# stop

> Stops the sniffer. The captured packets stay in memory for 10 minutes, or until the next start: list them in packet, protocol, host and connection, or write them to a file with save.

-----------

## tool/sniffer/stop 
**Type:** Command

Stops the sniffer. The captured packets stay in memory for 10 minutes, or until the next [`start`](start): list them in [`packet`](packet), [`protocol`](protocol), [`host`](host) and [`connection`](connection), or write them to a file with [`save`](save).
