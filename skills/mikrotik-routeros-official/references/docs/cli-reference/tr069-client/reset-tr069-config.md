## tr069-client/reset-tr069-config 
**Package:** tr069-client
**Type:** Command

Resets the tr069-client configuration and state to defaults without changing the rest of the RouterOS configuration. It is meant for a client that no longer responds or is stuck, so that it can be restored without reinstalling RouterOS.
