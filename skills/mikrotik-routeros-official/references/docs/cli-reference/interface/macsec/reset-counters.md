## interface/macsec/reset-counters 
**Conditions:** !smips
**Type:** Command

Reset all detailed MACsec SecY, Secure Channel (SC), and Secure Association (SA) counters to zero for the selected interface. See [MACsec](../../../bridging-and-switching/macsec) for counter interpretation and troubleshooting.
