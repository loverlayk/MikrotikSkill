# reset-counters-all

> Clears the byte and packet counters of all switch rules. On switches without ACL counters the command is not available.

-----------

## interface/ethernet/switch/rule/reset-counters-all 
**Syscap:** rbswitch and crs_prestera
**Type:** Command

Clears the byte and packet counters of all switch rules. On switches without ACL counters the command is not available.
