# reset-counters

> Clears the byte and packet counters of the specified switch rules. Pass the rule numbers as arguments, for example reset-counters 0. On switches without ACL counters the command is not available.

-----------

## interface/ethernet/switch/rule/reset-counters 
**Syscap:** rbswitch and crs_prestera
**Type:** Command

Clears the byte and packet counters of the specified switch rules. Pass the rule numbers as arguments, for example `reset-counters 0`. On switches without ACL counters the command is not available.
