# reset-freq-drift

> Resets the client's measured frequency drift of the local clock to zero, discarding the correction the client has learned. The estimate is rebuilt as the client keeps polling its servers. See the NTP guide.

-----------

## system/ntp/client/reset-freq-drift 
**Type:** Command

Resets the client's measured frequency drift of the local clock to zero, discarding the correction the client has learned. The estimate is rebuilt as the client keeps polling its servers. See the [NTP](../../../../system-information-and-utilities/ntp) guide.
