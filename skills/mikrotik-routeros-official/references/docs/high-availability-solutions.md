# High Availability Solutions

This section is about keeping the network working when a link or a device fails, and about using several links at the same time.

| You want to | See |
| :-- | :-- |
| Join several links between two devices into one | [Bonding](bonding) |
| Connect a device to two switches with one LACP bond | [Multi-chassis Link Aggregation Group](multi-chassis-link-aggregation-group) |
| Keep the gateway address of a network alive when a router fails | [VRRP](vrrp) |
| Use a second internet link when the first one fails | [Failover (WAN Backup)](load-balancing/failover-wan-backup) |
| Use two internet links at the same time | [Per connection classifier](load-balancing/per-connection-classifier) |
